# site-qa

สคริปต์ตรวจหน้าเว็บ (ไม่ได้ขึ้นเว็บจริง) — ใช้จำลองคนใช้งานหลายขนาดจอ

- audit.js: ตัวอักษรทับกัน / ล้นจอแนวนอน / ข้อความถูกตัด / ตัวหนังสือเล็ก / ปุ่มเล็กบนมือถือ / รูปเสีย
- contrast.js: ตรวจความตัดกันของสีตัวอักษรกับพื้น (WCAG)
- run.js: โหลดทุกหน้าใน iframe ตามความกว้างที่กำหนด แล้วรันสคริปต์ข้างบน — ใช้ un(skin, width, codeFile)`n
วิธีใช้: คัดลอกทั้ง 3 ไฟล์ไว้ใน assets ชั่วคราว (ชื่อ _audit.js _contrast.js _run.js) เปิดด้วยเซิร์ฟเวอร์ที่ไม่แคช แล้วเรียกผ่าน javascript ในเบราว์เซอร์
ต้องปิดแคชเซิร์ฟเวอร์ (Cache-Control: no-store) ไม่งั้นบางหน้าจะใช้ CSS เก่าค้างและผลตรวจเพี้ยน

## ตรวจของลอยทับบนมือถือ (เพิ่ม 8 พ.ย. 2026)
- overlay.js: ปุ่ม/ป้าย absolute ทับภาพหรือปุ่มอื่น (FLOAT-OVER) · ปุ่มใส่/ไม่ใส่เคสชิด/ทับภาพเครื่อง (TRYON-GAP) · เคสไม่ตรงกลางเครื่องหรือค้างกลางแอนิเมชัน (CASE-ALIGN / CASE-STUCK) · แถบ fixed บังปุ่มท้ายหน้า (FIXED-COVER)
- mobile-check.js: รัน overlay.js ทุกหน้า × ความกว้าง 320/360/390/430 × สถานะ (ทีละเคส / เทียบ 2 เคส / Galaxy / ไม่ใส่เคส)
  เปิด preview "site" (พอร์ต 8765 เสิร์ฟทั้งโฟลเดอร์) แล้วรันใน javascript ของเบราว์เซอร์:
  `eval(await (await fetch('/tools/site-qa/mobile-check.js',{cache:'no-store'})).text()); QA.start()` → รอ ~3–4 นาที → อ่าน `QA.last`
- ต้องได้ ALL OK ก่อนส่งงานที่แตะหน้าลองทาบ (assets/tryon.js, ส่วน .ty-* ใน site.css)
- ป้ายที่ตั้งใจวางบนรูปสินค้า (เช่น .cs-fit, .rg-n) อยู่ใน ALLOW ของ overlay.js — ป้ายใหม่ที่ตั้งใจให้ทับรูปให้ใส่ `data-overlay-ok`
