# PhoneCase Bot

บอทดึงราคาเคสมือถือ + โค้ดส่วนลดร้านจาก Shopee TH วันละรอบ แล้วคำนวณ **ราคาหลังใช้โค้ด** ส่งออกเป็น `data/products.json` ให้เว็บเอาไปแสดง

> บอทนี้อ่านหน้าเว็บ Shopee ซึ่ง **ผิดเงื่อนไขการใช้งานของ Shopee** มีโอกาสโดนจำกัดหรือแบนบัญชีที่ใช้ล็อกอิน
> ใช้บัญชีผู้ซื้อแยก ห้ามใช้บัญชีร้านค้าหรือบัญชี Affiliate และอย่าลดความเร็ว (delay) ลง
> พอขายครบ 1,000 ชิ้นแล้วให้เปลี่ยนไปใช้ Shopee Affiliate Open API แทน

---

## ติดตั้ง (ทำครั้งเดียว)

ต้องมี Windows 10/11 และ Python 3.9 ขึ้นไป ([python.org](https://www.python.org/downloads/) ตอนติดตั้งติ๊ก **Add python.exe to PATH**)

| ลำดับ | ดับเบิลคลิก | ทำอะไร |
|---|---|---|
| 1 | `1_setup/1_install.bat` | สร้าง environment + ติดตั้ง Playwright (ถ้าไม่มี Chrome จะโหลด Chromium ให้) |
| 2 | `1_setup/2_login.bat` | เปิดเบราว์เซอร์ของบอท ให้ล็อกอิน Shopee (บัญชีแยก) แล้วกด Enter |
| 3 | `2_run/3_run_bot.bat` | รันทันที 1 รอบ (ครั้งแรกควรรันเองเพื่อดูว่าผ่าน) |
| 4 | `3_schedule/4_schedule_daily.bat` | ตั้งให้รันอัตโนมัติทุกวันตามเวลาที่พิมพ์ (Task Scheduler) |
| 5 | `3_schedule/5_remove_schedule.bat` | ยกเลิกการตั้งเวลา |

ตอนตั้งเวลาไว้: คอมต้องเปิดและล็อกอิน Windows อยู่ ถ้าตอนนั้นปิดเครื่อง บอทจะรันตอนเปิดเครื่องครั้งถัดไป ระหว่างรันจะมีหน้าต่างเบราว์เซอร์เด้งขึ้นมา อย่าปิด

## ตั้งค่า `config.json`

เปิดด้วย Notepad แล้วบันทึกเป็น UTF-8 (คีย์ที่ขึ้นต้นด้วย `_` คือคำอธิบาย)

| คีย์ | ความหมาย |
|---|---|
| `searches` | คำค้นแต่ละรุ่น/สไตล์ เช่น `{"keyword": "เคส iphone 15 ลายน่ารัก", "model": "iPhone 15", "style": "น่ารัก", "max_items": 15}` |
| `product_urls` | สินค้าที่คัดเอง ให้เช็กทุกรอบ ใช้ลิงก์เต็มจากหน้าเว็บ (ลิงก์สั้น `s.shopee` อ่านไม่ได้) |
| `search_sort` | `sales` ขายดี / `relevancy` เกี่ยวข้อง / `ctime` ล่าสุด |
| `filters` | ราคาสูงสุด, เรตติ้งขั้นต่ำ, ยอดขายขั้นต่ำ |
| `exclude_words` | ตัดสินค้าที่ชื่อมีคำเหล่านี้ (กันลายลิขสิทธิ์ปลอม) |
| `check_vouchers_per_run` | เปิดหน้าสินค้าดูโค้ดร้านกี่ชิ้นต่อรอบ บอทหมุนเวียนให้เอง สินค้าที่มีลิงก์ affiliate ได้ก่อน |
| `voucher_max_age_days` | ข้อมูลโค้ดเก่ากว่ากี่วันไม่เอามาโชว์ |
| `delay_seconds`, `max_page_loads_per_run` | ความเร็ว ยิ่งช้ายิ่งปลอดภัย |
| `publish_only_with_affiliate_link` | `true` = products.json มีเฉพาะสินค้าที่ใส่ลิงก์ affiliate แล้ว |

## ลิงก์ affiliate (ทำครั้งเดียวต่อสินค้า)

ราคาอัปเดตอัตโนมัติ แต่ลิงก์ affiliate ต้องสร้างจากบัญชีคุณเอง

1. หลังรัน เปิด `need_affiliate_links.txt` จะมีลิงก์สินค้าที่ยังไม่มีลิงก์ affiliate
2. ก๊อปไปวางในเครื่องมือ "ลิงก์แบบกำหนดเอง" ที่ affiliate.shopee.co.th
3. เปิด `affiliate_links.csv` (บอทเพิ่มแถวสินค้าใหม่ให้แล้ว) วางลิงก์ที่ได้ลงคอลัมน์ `affiliate_link`
4. Excel: Save As แบบ **CSV UTF-8** แล้วปิดไฟล์ก่อนบอทรัน

## ผลลัพธ์ (โฟลเดอร์ `data`)

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `products.json` | ไฟล์ให้เว็บอ่าน เรียงตาม % ลดรวมมากสุดก่อน |
| `products_all.csv` | สินค้าทั้งหมด เปิดดูใน Excel |
| `price_history.csv` | ประวัติราคา ใช้คำนวณ "ต่ำสุดใน 30 วัน" |
| `last_run.json` | สถานะรอบล่าสุด |

ฟิลด์สำคัญใน `products.json`: `price` ราคาหน้าร้าน, `price_before_discount` ราคาก่อนลด, `best_price` ราคาหลังใช้โค้ดร้านที่ดีที่สุด (ซื้อ 1 ชิ้น), `best_voucher` โค้ดที่ใช้, `next_voucher` เช่น "ซื้อครบ ฿299 ลด ฿60", `save_pct` % ลดรวม, `lowest_30d`, `link`, `price_checked_at`

## บอทดึงตัวเลือกสินค้า (ขั้นที่ 2 ของ `2_run\10_collect_images.bat`)

`10_collect_images.bat` ทำ 2 ขั้นในรอบเดียว: (1) เก็บรูปอุปกรณ์เสริม (2) ดึงตัวเลือกสินค้า 8 ชิ้น — ขั้น 2 รันเฉพาะเมื่อขั้น 1 ไม่โดนบล็อก

เปิดหน้าสินค้าแล้วอ่าน **ตัวเลือกรุ่นมือถือที่ร้านขายจริง** (ตัดรุ่นที่ของหมด) + ตัวเลือกสี/ลาย พร้อมรหัสรูปตัวเลือก
→ เว็บขึ้น "✓ ยืนยันรุ่นแล้ว" ตามตัวเลือกจริง แทนการเดาจากชื่อสินค้า (ชื่อที่ไม่ระบุรุ่น เช่น Wishwindy เดิมไม่ขึ้นหน้ารุ่นไหนเลย)

- รอบละ 8 ชิ้น · ใช้ Chrome/ความช้า/พักยาวเดียวกับ `3_run_bot.bat` · เจอหน้ายืนยันตัวตน = กดเองในหน้าต่าง Chrome ของบอท
- ลำดับคิว: ชื่อไม่ระบุรุ่นก่อน → เคสที่ลองทาบได้ → ขายดี · ข้อมูลเก่ากว่า 14 วันดึงใหม่ · ระบุชิ้นเองได้: `.venv\Scripts\python.exe scripts\fetch_options.py 1382380664_24047313901`
- `scripts\fetch_options.py --dry` ดูคิวเฉยๆ ไม่เปิด Shopee
- ผล: `data\options.json` (รุ่นที่ซื้อได้ `phone`, รุ่นที่หมด `off`, สี `colors` {ชื่อ, รูป}) และ `..\assets\options.js` ให้เว็บอ่านทันที (ไม่ต้องรัน 6_publish)

## ถ้าบอทหยุดกลางทาง (`last_run.json` → `status`)

| status | แก้ยังไง |
|---|---|
| `blocked_verify` | Shopee ขอยืนยันตัวตน รัน `2_run/3_run_bot.bat` เอง แล้วยืนยันในหน้าต่างเบราว์เซอร์ บอทไม่กดแทน |
| `blocked_login` | หลุดล็อกอิน รัน `1_setup/2_login.bat` |
| `blocked_empty` | เปิด 2 หน้าแล้วไม่เจอข้อมูล อาจโดนจำกัดหรือ Shopee เปลี่ยนหน้าเว็บ พักสัก 1 วัน |

รอบที่หยุดกลางทางยังบันทึกผลที่ได้ และใช้ข้อมูลเดิม (ไม่เกิน 3 วัน) ของสินค้าที่ยังไม่ได้อัปเดต เว็บจะไม่หายครึ่งหนึ่ง

## ข้อจำกัด

- คิดเฉพาะ **โค้ดส่วนลดร้าน** ไม่รวมโค้ด Shopee ทั้งแพลตฟอร์ม, Coins และโปรบัตร ราคาจริงของลูกค้าแต่ละคนจึงอาจต่ำกว่านี้
- เป็นราคา ณ เวลาที่บอทเช็ก เว็บควรโชว์ `price_checked_at` และข้อความ "เช็กราคาจริงก่อนสั่งซื้อ"
- ถ้า Shopee เปลี่ยนโครงหน้าเว็บ บอทจะลองอ่านจากการ์ดสินค้าแทน ถ้ายังไม่ได้จะหยุดเอง (ไม่ยิงซ้ำ)
- `logs` เก็บ log แต่ละรอบ 30 วัน

## แก้ปัญหา

- **เปิดเบราว์เซอร์ไม่ได้** → รัน `1_setup/1_install.bat` อีกครั้ง หรือใน config เปลี่ยน `browser_channel` เป็น `""`
- **"เบราว์เซอร์ของบอทเปิดค้างอยู่"** → ปิดหน้าต่าง login หรือรอให้รอบที่ตั้งเวลาไว้รันเสร็จ
- **ภาษาไทยใน CSV เพี้ยนใน Excel** → เปิดผ่าน Data > From Text/CSV เลือก UTF-8
